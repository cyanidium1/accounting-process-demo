# Секція-демо процесу

Демо однієї секції для сайту бухгалтерської компанії: безперервний сценарій на
5 тактів (~11 с), зациклений з паузою 1,5 с. Тільки реальні DOM-елементи —
жодного відео, Lottie, canvas чи three.js, тому текст індексується й лишається
чітким на будь-якому екрані.

Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · GSAP 3 + ScrollTrigger.

## Запуск

```bash
npm install
npm run dev
```

## Як влаштована анімація

`components/sections/ProcessAnimation.tsx` — client component.

- Один майстер-таймлайн `gsap.timeline({ repeat: -1, repeatDelay: 1.5 })`.
  Такти розкладені абсолютними позиціями: 0.0 / 3.0 / 5.0 / 7.0 / 9.5.
- GSAP і ScrollTrigger підвантажуються ліниво — динамічним `import()` усередині
  ефекту; сама секція вантажиться окремим чанком через `next/dynamic`.
- Старт по ScrollTrigger при ~60% видимості (`start: "top 60%"`),
  `onLeave` / `onLeaveBack` ставлять на паузу, `onEnter` / `onEnterBack` —
  повертають. Додатково пауза на `visibilitychange`.
- Усе всередині `gsap.context()`, у cleanup — `revert()`.
- Анімуються тільки `transform` і `opacity` (виняток — `stroke-dashoffset`
  галочки в тості, він теж не викликає layout).

### Без layout thrashing

- Друк тексту не змінює розмір бульбашки: рядок розділений на надруковану
  частину і «хвіст» з `opacity: 0`, який тримає ширину. Загальна довжина
  тексту стала, тож переносів рядків не перераховує.
- Заливка дати акцентом — це окремий шар з `opacity`, а не анімація
  `background-color`.
- У кожному кадрі DOM тільки пишеться, ніколи не читається.

### SSR і reduced-motion

Розмітка на сервері віддається у **фінальному статичному стані**: повідомлення
надіслане, дві галочки на місці, картка задачі видима, дата 12 підсвічена,
галочка в тості намальована, лічильники з підсумковими числами. Тому:

- до гідрації немає стрибка — видно осмислену сцену;
- при `prefers-reduced-motion: reduce` таймлайн не створюється взагалі,
  користувач бачить той самий статичний кадр;
- увесь текст присутній у вихідному HTML і виділяється мишкою.

Початковий (прихований) стан виставляється синхронно в `useLayoutEffect`
через `data-anim="on"` — ще до першого кадру, тому статичний варіант не блимає,
поки вантажиться GSAP.

## Розкладка

- Десктоп: три колонки — чат, картка задачі, календар. Тост абсолютом над
  правою колонкою.
- Мобайл (<768px): вертикальний стек у тому ж порядку, календар стискається
  до одного тижня, бейджі дедлайнів переїжджають під тиждень, лічильники —
  у стовпчик.

## Деплой

Статичний експорт (`output: "export"`) → GitHub Pages через
`.github/workflows/deploy.yml`. `NEXT_PUBLIC_BASE_PATH` задає префікс шляху
для project-сторінки.
